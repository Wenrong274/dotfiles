# Vim 上手路徑（個人化版）

> 針對 **VSCode + vscode-neovim**，Leader = `Space`
> 從零開始到「不想回去用滑鼠」大約需要 **4 週**。
> 每週有明確的目標和每日練習量（每天 15–20 分鐘就夠）。
> 詳細說明見 [vim-guide.md](./vim-guide.md)，速查見 [vim-cheatsheet.md](./vim-cheatsheet.md)。

---

## 核心原則（先讀這個）

Vim 的學習曲線不是技術問題，是**習慣覆寫**問題。
你要覆蓋的舊習慣只有三個：

1. **移動時伸手拿滑鼠** → 改用 `hjkl` / `w` / `f` / Flash
2. **一直停在 Insert mode** → 打完就 `jj` 出來
3. **選取再操作** → 改用動詞 + 物件（`ciw` `da{` `yi"`）

> 只要這三個習慣改掉，你就超過 80% 的「Vim 使用者」了。

---

## 第 1 週：只練移動，其他照舊

**目標**：不用方向鍵，不用滑鼠點位置。

### 每日強迫規則

- ❌ 禁用方向鍵（Normal mode）
- ❌ 禁用滑鼠移動游標
- ✅ 移動只用下面這些鍵

### 本週要會的鍵（共 15 個）

| 分類 | 鍵              | 用途                              |
| ---- | --------------- | --------------------------------- |
| 基礎 | `h` `j` `k` `l` | 左下上右                          |
| 跳字 | `w` `b` `e`     | 下個 word / 上個 word / word 結尾 |
| 行內 | `0` `^` `$`     | 行首 / 非空行首 / 行尾            |
| 全檔 | `gg` `G`        | 檔首 / 檔尾                       |
| 跳行 | `:42<CR>`       | 直接跳到第 42 行                  |
| 頁面 | `<C-d>` `<C-u>` | 下半頁 / 上半頁                   |

### 相對行號（你的設定已開啟）

`editor.lineNumbers: "relative"` 是啟用狀態——左邊顯示的是**與游標的距離**，不是絕對行號。
（此為 VSCode `settings.json` 設定。使用 Settings Sync 會自動還原；或手動在 `settings.json` 加上 `"editor.lineNumbers": "relative"`）

```text
  3  func A() {
  2      foo()
  1      bar()     ← 游標上面 1 行
  5  }             ← 目前游標在這行（顯示絕對行號）
  1      baz()     ← 游標下面 1 行
  2  }
```

直接讀行號就知道要按幾下 `j`/`k`，不用目測猜數字。

### 每日練習（15 分鐘）

1. 開你正在寫的專案檔案
2. 用 `gg` 跳到檔首，目測一個函式，用 `G` 跳到檔尾
3. 找到一個你想改的地方，看左邊相對行號，直接按 `{n}j` / `{n}k` 跳過去（不猜距離）
4. 想用 `<Ctrl+Home>` 跳頂端時，改用 `gg`；想跳底端時改用 `G`

### 週末測試

- 從 `gg` 出發，只用鍵盤移動到一個你指定的函式名稱，不超過 30 秒

## 第 2 週：進入 Insert 的方式 + 第一批動詞物件

**目標**：不再「選取再刪除 / 選取再複製」，改用 `d`/`y`/`c` + 物件。

### 每日強迫規則

- ❌ 禁止「進 Insert 後用退格鍵刪一整個 word」→ 改 `ciw`
- ❌ 禁止「選取 → Ctrl+C → Ctrl+V」→ 改 `yiw` / `yy` / `p`
- ✅ 用 `jj` 或 `jk` 離開 Insert，不用 `<Esc>`（訓練小指休息）

### 本週要會的鍵

#### 進入 Insert 的六個入口

| 鍵  | 在哪裡開始打字       |
| --- | -------------------- |
| `i` | 游標前               |
| `a` | 游標後（append）     |
| `I` | 行首（第一個非空白） |
| `A` | 行尾                 |
| `o` | 新增下一行           |
| `O` | 新增上一行           |

> 常見情境：要在行尾加分號 `;` → `A` 進去打，不要先移動游標到行尾再按 `a`

#### 最重要的 7 個組合（先背這 7 個就夠）

| 指令       | 動作                                                   |
| ---------- | ------------------------------------------------------ |
| `ciw`      | 改一個 word（游標在 word 上任意位置都行）              |
| `ci"`      | 改 `"..."` 裡的內容                                    |
| `ci(`      | 改 `(...)` 裡的內容（函式參數）                        |
| `ci{`      | 改 `{...}` 裡的內容（block / method body — C# 最常用） |
| `diw`      | 刪一個 word                                            |
| `yiw`      | 複製一個 word                                          |
| `yy` / `p` | 複製整行 / 貼到下一行                                  |

> 規律：`c` (change) + `i` (inner) + 任何配對符號（`"` `'` `` ` `` `(` `[` `{` `<`）都成立。把 `c` 換成 `d` 是刪除，換成 `y` 是複製。

### 每日練習

1. 看到一個 string，用 `ci"` 改內容（不要先選取）
2. 看到一個函式呼叫，用 `ci(` 換參數
3. 看到一個變數名，用 `ciw` 改名（練習後可以換成 `<Space>r` 做 rename）
4. 刪一行用 `dd`，而不是「選取整行 → Delete」

### 週末測試

在你的程式碼裡找到一個需要改的 function，只用本週的鍵完成修改，不碰滑鼠。

## 第 3 週：你的個人映射 + 搜尋

**目標**：Leader 快捷鍵進肌肉記憶，`/` 搜尋取代 Ctrl+F。

### 每日強迫規則

- ❌ 禁用 `Ctrl+P` 開檔 → 改 `<Space>f`
- ❌ 禁用 `Ctrl+Shift+F` 全域搜尋 → 改 `<Space>/`
- ❌ 禁用 F2 rename → 改 `<Space>r`

### 本週要會的鍵

#### Leader 系列（先專注這 10 個）

| 鍵                | 功能                            |
| ----------------- | ------------------------------- |
| `<Space>f`        | Quick Open（開檔）              |
| `<Space>/`        | Find in Files（全域搜尋）       |
| `<Space>r`        | Rename（重新命名）              |
| `<Space>a`        | Quick Fix（燈泡建議）           |
| `<Space>v`        | 垂直分割視窗                    |
| `<Space>s`        | 水平分割視窗                    |
| `<Space>w`        | 關閉當前編輯器                  |
| `<C-h>` / `<C-l>` | 切換左 / 右視窗                 |
| `<C-j>` / `<C-k>` | 切換下 / 上視窗（水平分割後用） |

#### 搜尋

| 鍵            | 動作               |
| ------------- | ------------------ |
| `/foo`        | 搜尋 foo（向下）   |
| `n` / `N`     | 下一個 / 上一個    |
| `*`           | 搜尋游標下的 word  |
| `<Space><CR>` | 清除搜尋 highlight |

#### LSP 導覽

| 鍵      | 功能             |
| ------- | ---------------- |
| `gd`    | Go to Definition |
| `gr`    | Go to References |
| `<C-o>` | 跳回上一個位置   |

### 每日練習

1. 開檔用 `<Space>f`，一天用 10 次以上直到不假思索
2. 看到未知函式，`gd` 跳定義，`<C-o>` 跳回來
3. 要改變數名，`<Space>r` 直接 rename

### 週末測試

完成一個小功能（新增 / 修改 / 重構），全程不用 VSCode 工具列按鈕，只用鍵盤。

## 第 4 週以後：進階工具，按需取用

不要一次全學。遇到痛點時對應取用：

### 痛點 → 解法對照

| 你遇到的情境                          | 學這個                                            |
| ------------------------------------- | ------------------------------------------------- |
| 在一大段程式裡跳到螢幕上某個字        | Flash.nvim：`<Space><Space>` + 打目標字元         |
| `dd` 刪行後，貼上發現是刪的不是複製的 | Registers：`"0p` 貼 yank 內容，或 `"_dd` 黑洞刪除 |
| 想把 `"foo"` 換成 `'foo'`             | Surround：`cs"'`                                  |
| 想包覆一個 word 成 `(word)`           | Surround：`ysiw)`                                 |
| 要對 C# 的 `MyVariableName` 拆字移動  | CamelCaseMotion：`,w` `,b`                        |
| 要對 20 行做同樣的編輯                | Macros：`qa` 錄製，`q` 結束，`19@a` 執行          |
| 要每行行首加 `//`                     | Visual Block：`<C-q>` 選行，`I// <Esc>`           |

### Flash.nvim 快速說明

```text
<Space><Space>   →   開始打目標文字（打 1~2 字元）
                 →   畫面出現標記字母
                 →   按字母   →   跳到該位置
```

> 比 `f{c}` 強在可以跨行跳，不需要記或目測幾個字元。

### Macros 最小可用版

```text
qa          開始錄到 register a
{操作一次}
q           停止錄製
@a          播放一次
10@a        播放 10 次
```

> 先從「對一行做 3 步操作，需要對 5 行都做」的情境練起。
